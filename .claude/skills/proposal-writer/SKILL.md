# proposal-writer

## Ler antes
`docs/PRODUCT_CONTEXT.md` (oferta), `docs/CLIENT_WEBSITES.md` §4 (ambição por pacote) e o diagnóstico do `website-audit`, se houver.

## Processo
1. Confirmar os dados do lead e o diagnóstico (marcar o que é inferido).
2. Escolher o pacote de referência (Essencial R$590 / Profissional R$990 / Personalizado a partir de R$1.490) **após analisar o escopo**; valores são editáveis e confirmados pelo fundador.
3. Estruturar: problema observado → solução proposta → escopo (páginas, seções, funcionalidades) → conteúdo que o cliente fornece → entregáveis → prazo → número de revisões → exclusões → custos recorrentes à parte (domínio, hospedagem, manutenção) → valor em BRL, entrada 50% e saldo 50% (ou conforme acordo) → validade → aceite.
4. Linguagem concreta e sem buzzwords (revisar com `humanizer`, se disponível).

## Não fazer
Garantir resultados (vendas, ranking); prometer integrações não implementadas; fixar preço final sem aprovação humana; enviar ao cliente.

## Saída
Proposta pronta para revisão humana, com pendências e premissas listadas.
